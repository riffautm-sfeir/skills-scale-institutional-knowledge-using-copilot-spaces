
# OctoAcme Project Management Docs

This README is the entry point to OctoAcme's project management documentation.

## Project management processes

OctoAcme manages projects through a consistent project management lifecycle: teams define the need and stakeholders during initiation, plan scope and work, execute and track progress, manage risks and communication, release and deploy changes, then capture lessons through retrospectives and continuous improvement. Roles and responsibilities help coordinate this work across the team.
